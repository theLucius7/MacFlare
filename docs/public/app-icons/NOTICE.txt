Application icons

These PNGs were exported from the configured applications installed on the maintainer's Mac, using native macOS tools. They are application identification assets, not cached macOSicons API responses.

Application icons, names and trademarks belong to their respective software authors. These assets are **not covered by MacFlare's MIT code license**; retaining them here does not grant ownership or permission for unrelated reuse.

`index.json` records stable identifiers, display aliases, image API paths and SHA-256 checksums. It contains no local installation paths or user data.

To refresh selected icons on macOS, edit `config/app-icons.json` and run `npm run icons:export`, then review and commit the resulting PNGs and manifest. See [the icon guide](https://macflare.lucius7.dev/app-icons) for the static image URLs, API and optional macOSicons integration.
